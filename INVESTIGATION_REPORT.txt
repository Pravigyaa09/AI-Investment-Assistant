CRITICAL ISSUE FOUND
====================

Location: backend/app/routers/news.py lines 48-51
Problem: Sequential task awaiting instead of parallel execution

Current Code:
  for ticker, task in tasks:
      rec = await task  # Blocks until complete
      results[ticker] = rec

Issue:
  - Creates 15 tasks in parallel (good)
  - But awaits them SEQUENTIALLY (bad)
  - Result: 15 seconds instead of 1 second
  - Impact: 10-15x latency penalty

Fix (5 minutes):
  all_tasks = [task for _, task in tasks]
  results_list = await asyncio.gather(*all_tasks, return_exceptions=True)
  for (ticker, _), rec in zip(tasks, results_list):
      if isinstance(rec, Exception):
          results[ticker] = FALLBACK
      else:
          results[ticker] = rec
